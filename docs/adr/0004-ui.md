# ADR 0004 — Viewer nativo Windows

Estado: implementado; smoke automatizado Windows incluído no CI.

A interface usa Win32/common controls diretamente em Go, com ListView virtual
(LVS_OWNERDATA), polling cancelável, processamento fora da thread da janela e
limites de retenção. A opção reduz o setup do projeto secundário: não requer CGO,
compilador C nem instalação de toolkit no alvo. Fyne foi apenas candidato e não
foi incorporado. Essa escolha atende Windows x64 como alvo inicial e mantém
collector, domínio e visualizador separados.

A interface oferece seleção/start/stop, ranking, filtros por texto e thread,
intervalo, gráfico de atividade, detalhes, salvar/replay e comparação resumida.
CLI permanece disponível para automação e comparação completa. Não existe
porcentagem de CPU nem métricas de chamadas estimadas a partir de amostras.

O smoke de janela valida inicialização/encerramento, não substitui medições de
responsividade, legibilidade e custo em cargas reais. Layout Win32 não oferece
portabilidade gráfica para Linux/macOS, que usam o CLI.
