# ADR 0004 — Viewer

Estado: Fyne candidato, decisão adiada ao spike Windows.

Fyne permite UI escrita em Go; README oficial confirma compilador C e ferramentas
de desenvolvimento. “Código próprio em Go” não implica ausência de CGO ou de
bibliotecas nativas. Collector/domínio permanecerão sem dependência de Fyne.

Provar build em Windows amd64, operação gráfica e widget.Table com 100 mil linhas
sintéticas (carga proposta, não capacidade medida), filtros e ordenação fora da
thread de UI. Testar 2–4 atualizações/s de tabela e coalescência, com p50/p95 de
atraso, RAM e responsividade. Fixar budgets após baseline de hardware.

Apenas a thread/event loop permitida pelo toolkit modifica widgets. Worker
entrega resultado imutável com geração; resultado antigo de filtro é ignorado.
Encerrar janela cancela workers do viewer, não mata collector implicitamente.

CLI de pesquisa antes da UI. Wails somente se houver insuficiência medida e ADR
novo, reconhecendo frontend adicional. Não instalar Fyne nesta prova PE.
